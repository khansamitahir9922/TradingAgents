## Goal
Implement effective-dated provider symbol mappings (ADR-003): "which instrument did provider P mean by symbol S on date D?", and the reverse.

## Allowed files
- `investment_engine/market/symbols.py` (new)
- `tests/engine/test_symbols.py` (new)
- `docs/tasks/M1-04.md`, `PROGRESS.md`

## Contracts
```python
PROVIDER_YFINANCE = "yfinance"

@dataclass(frozen=True)
class SymbolMapping:
    instrument_id: str
    provider: str            # lowercase, e.g. "yfinance"
    symbol: str              # as the provider spells it
    valid_from: date
    valid_to: date | None    # half-open [valid_from, valid_to)

class UnknownSymbol(LookupError): ...

class SymbolResolver:        # in memory; SQLite-backed in M1-05 with the same interface
    def add(self, mapping: SymbolMapping) -> None
    def resolve(self, provider: str, symbol: str, on: date) -> str      # -> instrument_id
    def symbol_for(self, instrument_id: str, provider: str, on: date) -> str
```

## Implementation choices
**Resolved**
- **Exchange-local calendar dates** (`date`), half-open intervals.
- **Two overlap rules, both rejected on `add`:**
  1. the same `(provider, symbol)` mapped to two instruments over overlapping dates;
  2. the same `(instrument_id, provider)` with two symbols over overlapping dates.
- **A missing mapping raises `UnknownSymbol`.** It never falls back to "the ticker is probably the same".
- Symbols are matched **exactly**, so case is preserved as the provider spells it.

**Unresolved:** none.

## Acceptance tests
- Lookups before, at the start of, inside, at the end of (exclusive), and after a mapping's validity.
- A reused symbol resolves to different instruments on different dates, using two non-overlapping mappings.
- A ticker change (old symbol until D, new symbol from D) resolves correctly on both sides of D in both directions.
- Each overlap rule is rejected.
- Unknown lookups raise `UnknownSymbol`.

## Out of scope
Persistence (M1-05); industry identifiers (FIGI, ISIN), which can be added later as further mappings.
