## Contracts

The [M5 shared contracts](M5-README.md#shared-contracts) and accepted ADR-010 govern this task. Proposed rules for this task:

1. Implement M5-README C1/C2 and ADR-010 fields as immutable registered dataclasses, preserving existing serializer behavior. `SourceBundle` carries validated stored-source references, effective/available/delivered times, provider, completeness and model version; no bare boolean can establish history.
2. Define `CostBasisPort` and `SnapshotProvider` protocols here. SELL posting requires an explicit lot-consumption plan; future FIFO code implements that port. Broker DTOs stay neutral: Core cannot import execution/broker_port.py.
3. A reversal identifies its original entry and transaction; validate same investment account and same unit. `posted_at` and `effective_at` remain different fields. Reject a posting purportedly known before its source.
4. A BookBatch has stable parent/version/source-set identity and an immutable ordered transaction/entry manifest. A header declares entry count and hash so a later append cannot extend a committed transaction.

## Implementation choices

- **Owner-approved, 2026-10-21:** D35-D44 and ADR-010 v0.2; do not silently choose a different policy.
- No new process, broker, account authority, serializer rewrite or order edge. Fail explicitly when a required source/contract is unavailable.
- All production time uses injected clocks; money/quantities are Decimal; source/provider separation and no-look-ahead rules apply.
- A discovered architecture gap, out-of-scope file or new test failure stops the package and is reported before dependent work.

## Acceptance tests

- Finite Decimal only; no floats, NaN/infinity, mixed units, missing IDs, naive/non-UTC times or invalid date/datetime substitution.
- Stable content identities under input-order normalization; account and provider changes alter identity; command-time changes do not.
- Round-trip new records without changing captured legacy serialization; unsupported snapshot fields are missing, not zero.
- Hand-checked entry directions for every ADR-010 example; invalid cross-account reversal refused.
