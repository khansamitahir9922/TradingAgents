## Contracts

The [M6 shared contracts](M6-README.md#shared-contracts) govern this task.

2. Reservation under `budget|<UTC day>` lock; refuse when reserved+used would exceed requests/tokens/USD caps; refusal recorded as BUDGET_REFUSED with numbers.
3. Actual usage appended after the run; unknown tokens count the reservation's tokens (conservative), never zero.
4. UTC day boundary uses the injected clock.
