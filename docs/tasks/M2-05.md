## Goal
Implement two simple, transparent daily strategies on NVDA, to exercise the full path from data to MarketView to evaluation:
- **A1, trend:** the regime from the 200-day average and the 50/200 average state;
- **A2, pullback within the trend:** RSI extremes, taken only in the direction of the 200-day trend.

## Allowed files
- `investment_engine/quant/strategies/trend.py`, `investment_engine/quant/strategies/pullback.py` (new)
- `tests/engine/test_first_strategies.py` (new)
- `docs/tasks/M2-05.md`, `PROGRESS.md`

## Contracts
```python
class TrendStrategy(RuleStrategy):
    name = "daily-trend"; version = "0.1.0"
    def evaluate(self, snapshot: FeatureSnapshot) -> StrategySignal | None

class PullbackStrategy(RuleStrategy):
    name = "daily-pullback"; version = "0.1.0"
    def evaluate(self, snapshot: FeatureSnapshot) -> StrategySignal | None
```
Both declare immutable required sources/actions/features from the rules below and use M2-04's guarded feature access. Each returns only a validated StrategySignal for its own identity/version.

## Strategy rules
**Shared:**
- required sources `(yfinance, D1)`;
- required actions `(SPLIT,)`;
- features on `SPLIT_ADJUSTED_AS_OF`;
- version `0.1.0`.

**A1, trend** (features `sma50`, `sma200`, `dist_sma200`):

| Condition | Direction |
|---|---|
| close > SMA200 **and** SMA50 > SMA200 | BULLISH |
| close < SMA200 **and** SMA50 < SMA200 | BEARISH |
| otherwise | NEUTRAL |

`strength = min(1, |dist_sma200| / 0.10)`, so 10% from the average is full strength. It is documented as a **distance scale, not a probability**.

**A2, pullback** (features `rsi14`, `dist_sma200`):

| Condition | Direction |
|---|---|
| close > SMA200 **and** RSI ≤ 30 | BULLISH |
| close < SMA200 **and** RSI ≥ 70 | BEARISH |
| otherwise | NEUTRAL |

`strength = min(1, |RSI - 50| / 50)`.

**Parameters are fixed** at the values above once this draft is accepted. Nothing is fitted in M2, so there's no tuning to leak. Changing any parameter is a new version.

## Implementation choices
**Resolved:** each strategy's reasons name the rule and the values that fired (e.g. "close 4.2% above SMA200; SMA50 above SMA200").
**Unresolved:** review and acceptance of the precise rules, periods and strength scales above. OPEN-06 option A sets the two-strategy daily research scope; it doesn't approve paper execution or profitability claims.

## Acceptance tests
- Each row of both tables is reached from a hand-built snapshot. Equality with SMA200 gives NEUTRAL; RSI exactly 30 or 70 satisfies the corresponding inclusive rule. Equality of SMA50 and SMA200 gives A1 NEUTRAL.
- Strength is in [0, 1] and is labelled as a scale.
- Warm-up (SMA200 missing) gives `None`.
- The declared required sources and actions are as above.

## Out of scope
Combining strategies into one view (M2-06's policy); parameter search (none in M2).
