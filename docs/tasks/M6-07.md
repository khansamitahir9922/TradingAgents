## Contracts

The [M6 shared contracts](M6-README.md#shared-contracts) govern this task.

1. Loop: claim (lease) → budget reserve → adapter run outside any DB transaction → one atomic save → publish. Lease renewal while running; a crashed run's lease expires and the job is re-claimable once; a second attempt is a new run record with the earlier attempt's outcome kept.
2. Startup refuses if broker-credential variables or the execution worker secrets file are readable, or if the research secrets file is missing; it loads only `research_worker.env` into its own process environment (D48). Output never prints secrets or the DSN.
3. Reconnect on lost DB connection with typed propagation as in M4 R5; a stuck LLM call is bounded by a configured per-run deadline and marked FAILED.
4. Layering: research may not import execution/oms writers/ledger writers/policy writers/killswitch; Core/execution/oms/ledger/policy/risk may not import tradingagents or investment_engine.research.adapter.

## Implementation/check record

The Research Worker process, `python -m investment_engine.research run [--once]`. Each step claims one job with a lease covering the whole bounded run (deadline plus 5 minutes), reserves the day's budget (refusal recorded BUDGET_REFUSED without running), runs the adapter in a thread outside any transaction under the deadline, builds the context, then saves record, context, ACTUAL usage, final version and event atomically and publishes. A successful run without a usable rating is saved FAILED with its reason and no context. A run past its deadline is saved FAILED ("abandoned; its reservation stays counted") and the worker starts nothing new until the stuck thread returns, as M4 does for a stalled broker call. A lost database connection keeps its type and reaches the reconnect, keeping any stall; without a reconnect it is raised. Startup (D48) refuses, before touching the database and without printing any value: a missing `research_worker.env`; a key in it that is not an LLM or research-data key; any LLM key already in the inherited environment; any broker-looking variable; or a visible Execution Worker secrets file. Keys load only into this process's environment. New layering rule: the research package imports no execution, kill-switch, ledger (except the pure identity hash in ledger.contracts), reconciliation, risk, portfolio or OMS writer modules.

Deviation from the spec text: no in-place lease renewal. The lease outlives the deadline, so a running job is never re-claimable, and every claim stays a clean compare-and-set (M6-02's design note). A crashed claim is re-claimed once after expiry, here simulated in-process with an abandoned claim; the real hard-killed process is M6-10's.
