## Goal
Build chronological folds and run the fixed rule strategies through them, with no fitting, no incomplete or late labels in training, and no promotion. The run records produced here are stored by M2-11b.

## Allowed files
- `investment_engine/evaluation/walk_forward.py` (new)
- `tests/engine/test_walk_forward.py` (new)
- `docs/tasks/M2-11.md` (status), `docs/tasks/M2-11a.md`, `PROGRESS.md`

## Contracts
`Fold`, `WalkForwardConfig` and `make_folds` as in [M2-11](M2-11.md); final interfaces below. `walk_forward` returns the per-fold `EvaluationRun`s (M2-10) together with each fold's boundaries, purge and exclusion counts, warm-up and limitations, in one immutable result.

## Rules
[M2-11](M2-11.md) rules 1, 2, 3, 4 and 6. The provisional windows are 24 months train, 6 months test, 6-month step (owner, 2026-10-14).

## Acceptance tests
[M2-11](M2-11.md) acceptance cases 1, 2, 3, 4 and 6.

## Final interfaces (implemented; extensions accepted in principle by Codex's review of `57d4316`, 2026-10-15)
```python
def walk_forward(folds, *, views: Sequence[PredictionView], reader, calendar, source, instrument_id,
                 coverage_evidence, coverage_first, coverage_last, coverage_reason, evaluation_config, at,
                 fit_steps=(), impute_required_sources=False) -> WalkForwardResult
@dataclass(frozen=True)
class FoldResult: fold; train_views; train_labels_eligible; train_labels_purged; test_views; warmup_views; direction; run
@dataclass(frozen=True)
class WalkForwardResult: folds; stitched; stitched_label; promotion; limitations
class RevisionCache:   # read-only in-memory PIT projection, tested equal to the store reader
    @classmethod
    def load(cls, reader, source, instrument_id, timeframes=(Timeframe.D1,)) -> "RevisionCache"
```
Views are the replay's precomputed views; folds must be ordered and non-overlapping (S2); only views generated by `at` are evaluated (B3).

## Out of scope
Persistence (M2-11b); ML fitting and calibration (M9); promotion.
