## Goal
Build chronological folds and run the fixed rule strategies through them, with no fitting, no incomplete or late labels in training, and no promotion. The run records produced here are stored by M2-11b.

## Allowed files
- `investment_engine/evaluation/walk_forward.py` (new)
- `tests/engine/test_walk_forward.py` (new)
- `docs/tasks/M2-11.md` (status), `docs/tasks/M2-11a.md`, `PROGRESS.md`

## Contracts
`Fold`, `WalkForwardConfig`, `make_folds` and `walk_forward` exactly as in [M2-11](M2-11.md). `walk_forward` returns the per-fold `EvaluationRun`s (M2-10) together with each fold's boundaries, purge and exclusion counts, warm-up and limitations, in one immutable result.

## Rules
[M2-11](M2-11.md) rules 1, 2, 3, 4 and 6. The provisional windows are 24 months train, 6 months test, 6-month step (owner, 2026-10-14).

## Acceptance tests
