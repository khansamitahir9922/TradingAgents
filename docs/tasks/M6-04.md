## Goal

Run one TradingAgents propagation behind a port and capture everything needed for reconstruction.

## Dependencies

M6-01, M6-03. Same-package predecessors must be committed and checked; external prerequisites merged (M5 is merged locally).

- `investment_engine/research/adapter.py`
- `investment_engine/research/capture.py`
- `tests/engine/test_adapter.py`
- `docs/tasks/M6-04.md`, `docs/tasks/M6-README.md` (task status/check record only), `PROGRESS.md`

Anything else triggers the stop rule.

## Contracts

The [M6 shared contracts](M6-README.md#shared-contracts) govern this task.

1. `ResearchPort.run(job, *, clock) -> RunOutput` builds `TradingAgentsGraph` from the job's frozen settings (pinned models, `llm_max_retries=0`, checkpointing off, results directory under the worker's data dir) and the M6-00 callback.
2. Capture: every LLM call's messages and response, every tool call/result, data-vendor/endpoint/fetched_at references, final state (reports, structured objects from M6-03), upstream version and repository code version, warnings, usage.
3. Ticker comes from the existing SymbolMapping for the instrument; the run date must equal the current exchange date (D50) or the job is refused before any LLM call.
4. Exceptions are captured as outcome FAILED with type and sanitized message; secrets are never captured (prompts are scanned for the loaded key and redacted, with a test).

## Implementation choices

- Owner decisions D45-D54 govern; do not silently choose differently. Until accepted, this is a draft.
- No new process beyond the architecture's Research Worker, no broker capability, no change to MarketView, sizing, policy, risk, gate, OMS or ledger behaviour.
- Injected clocks only; Decimal for money; aware UTC times; untrusted text stays untrusted (Law 4).
- A spec gap needing an architecture/ADR change, a file outside the allowed list, or a new test failure stops the package.

## Acceptance tests

- Fake LLM/tool run produces a complete RunOutput; every agent's prompt is captured in order.
- A historical date is refused with zero LLM calls.
- A raised provider error yields FAILED with no partial structured context; the API key never appears in captured text.
