## Goal
Turn strategy signals and DataHealth into the **MarketView** contract (Part H). The policy is deterministic and versioned. **Missing data forces abstention** (Law 9).

## Allowed files
- `investment_engine/decision/__init__.py`, `investment_engine/decision/market_view.py` (new)

## Contracts
```python
class ViewDirection(StrEnum): BULLISH, BEARISH, NEUTRAL, ABSTAIN

@dataclass(frozen=True)
class MarketView:                       # Part H fields
    instrument_id: str
    direction: ViewDirection
    strength: float                     # 0 – 1, not a probability; 0 when ABSTAIN
    probability_up: float | None        # always None for rule strategies
    horizon: str                        # "5 sessions" (OPEN-09 draft)
    generated_at: datetime              # T
    valid_until: datetime               # provisional rule below
    regime: str | None                  # A1's direction, as context
    data_health: DataHealth
    evidence_refs: tuple[str, ...]      # lineage id(s) (M2-07)
    policy_version: str
    abstain_reason: str                 # "" unless ABSTAIN
    reasons: tuple[str, ...]            # rule explanations, including consistency-neutral

def decide(strategy_signals: Sequence[StrategySignal | None], snapshot: FeatureSnapshot,
           strategies: Sequence[RuleStrategy], *, policy_version: str, calendar,
           evidence_refs: tuple[str, ...] = ()) -> MarketView
```

## Rules
1. **Law 9:** if any source required by **any** of the strategies isn't `OK` at T, or the instrument isn't applicable, the view is **ABSTAIN**, with the reason naming the sources and their statuses.
   - This is stricter than Law 9's minimum (STALE or MISSING): **DEGRADED also abstains**, because holes in the lookback can distort indicators.
   - Unestablished action coverage or `snapshot.unavailable_reason` also abstains. An established, empty split range is valid and is not treated as a missing source.
2. **Warm-up:** if any strategy returns `None`, the view is ABSTAIN with reason "warm-up". There's no partial combination.
3. **Combination policy v0.1:**
   - A1 sets the regime.
   - The direction is A1's, unless A2 fires **in the same direction**, in which case strength is the maximum of the two.
   - If A2 fires **against** A1 (impossible by A2's rules, so it's a consistency check), the view is NEUTRAL with a reason.
   - With option B (A1 only), the direction is A1's.
4. **Provisional `valid_until`:** the close of the next session after T (calendar). OPEN-08 replaces it. An expired view shows as WAIT in the UI (Part H UI mapping).
5. **No probability:** `probability_up` is always `None` here.
6. **Determinism:** the same snapshot, signals and policy version give an identical view.
7. Require one correctly identified/versioned signal slot per strategy, a non-empty distinct strategy set, matching instrument/T/health, and all declared required sources present. A missing health entry abstains, never passes an `all()` check over an empty subset. Non-finite/out-of-range strength raises. Neutral output has zero directional strength. Reasons remain visible even for consistency-neutral output.
8. The standalone policy can return an unpersisted view with empty `evidence_refs`; M2-07 hashes the decision context excluding `evidence_refs`, appends that immutable context, then returns a copy with its lineage ID. Only this enriched view is reportable. This avoids a circular lineage hash.

## Implementation choices
**Resolved:**
- The policy version is a string in the view, and every change to these rules bumps it.
- ABSTAIN is the policy's output, never a strategy's.

**Resolved for M2 (owner, 2026-10-14):** the provisional `valid_until` above is accepted as a research assumption. **Still open:** the final **OPEN-08** validity window, owner, by M3.

## Acceptance tests
- Each source status (OK, STALE, MISSING, DEGRADED) and not-applicable: only all-OK and applicable gives a non-ABSTAIN view. The reason names every non-OK source.
- Warm-up abstains.
- Missing health entries and unestablished action coverage abstain; established empty action history does not. Mismatched signal identities, versions/counts and invalid strength raise.
- The combination table, including the consistency case.
- `strength` is 0 when abstaining and in [0, 1] otherwise. `probability_up` is always `None`.
- `valid_until` is the next session's close; across a weekend and a holiday too.
- **Replay determinism:** views generated from a replay (M1-14) twice are identical.
