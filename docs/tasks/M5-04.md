## Contracts

The [M5 shared contracts](M5-README.md#shared-contracts) and accepted ADR-010 govern this task. Proposed rules for this task:

1. Implement ADR-010 section 4 and C3. Ex-open actions precede fills at that instant; announcements alone do not post. Select provider-separated revisions with both availability and actual replay delivery restrictions.
2. A split preserves lot cost and changes lot quantities/quantity-book entries. Reverse splits use the appropriate opposite entry directions; unsupported fractions make the account unavailable without a partial batch.
3. A dividend recognizes prior-close entitlement as a receivable, not CASH. A later ex-date fill does not affect that entitlement. Do not infer or model payment dates.
4. For a revised action with no later dependencies, append complete reversals/replacements atomically. If later FIFO/distribution dependencies exist, return a typed closure-required result for M5-05; do not publish an incomplete correction.
5. Unresolved orders crossing an action, absent coverage, unsupported types or wrong currency preserve M4 refusal and reservations. No order terms are transformed.
