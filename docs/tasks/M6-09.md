## Contracts

The [M6 shared contracts](M6-README.md#shared-contracts) govern this task.

1. Panel shows: rating, trader action, untrusted suggested levels (labelled), generated_at, valid_until with VALID/EXPIRED status, warnings, provider/models, run_id link, 'ADVISORY — not used by sizing, risk or orders' and 'reconstructable, not reproducible'.
2. Missing research shows 'No research' (never a default rating); expired shows EXPIRED; all text HTML-escaped; status is never colour-only.
3. Existing report outputs without research are byte-identical.
