## Contracts

The [M6 shared contracts](M6-README.md#shared-contracts) govern this task.

1. Rating from `final_decision_structured.rating` (source=typed); if absent, upstream's text rating parser result with source=free-text-fallback and a warning; if neither, no context (outcome FAILED: no rating).
2. Trader action and levels from `trader_proposal_structured`; levels converted to Decimal exactly from their string form, else None with a warning; never inferred from text.
3. `valid_until` per D51 from the injected calendar; horizon recorded.
4. Warnings: fallback used, missing levels, analyst report empty, tool errors seen, usage unknown.

## Implementation/check record

`build_context` turns a successful run into a ResearchContext. The rating comes from the parsed Portfolio Manager decision (U1, source TYPED); without one, from the 5-tier `final_rating` upstream itself parsed from the decision text (source FREE_TEXT_FALLBACK, with a warning). The research package may not call upstream's parser directly (layering), and needs not to. No valid rating, or a failed run, gives `NoResearchContext` (recorded FAILED by the worker). Action and levels come only from the parsed Trader proposal; levels convert from the number's decimal string form, and non-numbers, percentages, ranges, non-finite or non-positive values are dropped with a warning. Warnings name empty reports, failed tools, unknown token usage and the run's own warnings. Report text is never read for fields, so an injected instruction adds nothing. `valid_until` is the close of the 5th session opening after generation, on the cited exchange calendar (weekend and the Jan 19 2026 holiday tested); an override can only shorten it.
