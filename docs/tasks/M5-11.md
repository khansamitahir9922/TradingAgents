## Contracts

The [M5 shared contracts](M5-README.md#shared-contracts) and accepted ADR-010 govern this task. Proposed rules for this task:

1. Implement C3/C5 and D40: CLI/JSON/static HTML share one immutable report model pinned to account, book and E/K cutoffs. Render Decimal units/times/source IDs and explicit missing values.
2. Report net/gross realized, unrealized, fees, receivables, cash, positions/lots, capital/equity bridge, reconciliation evidence and incident history. Daily values require complete comparable endpoints.
3. Historical PROVISIONAL reports stay historical; LEDGER applies only after activation. Label simulated research NOT PROMOTED. Escape HTML text and provide accessible non-color-only statuses; never render unknown as zero.
4. Report commands use read-only database connections and do not migrate/sync/acknowledge as a side effect. Activation, sync and incident writes are separate explicitly named Admin commands with recorded reasons and role checks.
5. Existing CLI registrations and prior report outputs remain compatible; no existing tests are weakened.
