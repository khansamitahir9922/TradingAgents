## Goal
Make time explicit (architecture Law 5). Business code gets the time from an injected `Clock`, never from the system. Every datetime in a contract is timezone-aware UTC.

## Allowed files
- `investment_engine/clock.py` (new)
- `tests/engine/test_clock.py`, `tests/engine/test_no_system_clock.py` (new)
- `docs/tasks/M1-01.md`, `PROGRESS.md`

## Contracts
```python
class Clock(Protocol):
    def now(self) -> datetime: ...          # aware, tzinfo == UTC

class LiveClock:                            # the only place that reads the system clock
    def now(self) -> datetime

class ReplayClock:
    def __init__(self, start: datetime)     # start must be aware; stored as UTC
    def now(self) -> datetime
    def advance_to(self, t: datetime) -> None   # t >= now(), else ValueError (never goes backwards)
    def advance_by(self, delta: timedelta) -> None  # delta >= 0

def ensure_utc(dt: datetime) -> datetime
    # aware -> converted to UTC; naive -> ValueError
```

## Implementation choices
**Resolved**
- **UTC everywhere** in contracts. Exchange-local time is used only where a calendar or display needs it (M1-06, M1-17).
- `ensure_utc` **rejects naive datetimes** rather than assuming a zone.
- **`ReplayClock` is monotonic.** Moving backwards is a bug, so it raises.
- **Sequence numbers for equal times aren't part of the Clock.** They belong to the replay feed (M1-14), where events are ordered.
- **"No system clock" check:** an AST test scans `investment_engine/` and fails on any call to `datetime.now`, `datetime.utcnow`, `datetime.today`, `date.today`, `time.time`, `time.time_ns`, `time.localtime` or `time.gmtime` outside `investment_engine/clock.py`.

**Unresolved:** none.

## Acceptance tests
- `LiveClock().now()` is aware, with UTC tzinfo.
- `ReplayClock`:
  - `now()` returns the start;
  - `advance_to` a later time works;
  - `advance_to` an earlier time raises;
  - `advance_by(negative)` raises;
  - a naive start raises.
- `ensure_utc` converts an aware `America/New_York` time correctly across a DST change, and rejects a naive one.
- `test_no_system_clock.py` passes, and a planted call in a temporary file makes the scan fail (a test of the test).
- The tests don't depend on the machine's time zone. The CI `TZ=America/New_York` run checks this once CI runs.

## Out of scope
Calendars, sessions and display formatting.
