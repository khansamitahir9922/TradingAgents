## Implementation/check record

ResearchBudget enforces D46 and fails closed. Only a current Admin sets a versioned, audited policy (operator lock, then live command-time authorization against the stored registry; Trader, Viewer and a deactivated Admin are refused). Before a run the worker reserves the policy's per-run requests and tokens under the UTC day's lock; it is refused with the numbers when the day's total would exceed a cap, and refused when no policy exists. Reservations are idempotent per run. A run's measured ACTUAL usage replaces its reservation in the day's total; unknown measured tokens count the reserved tokens, never zero. A USD cap cannot be enforced before per-run prices are measured (M6-11), so a policy with a USD cap refuses runs: D47's USD 0 monthly budget is the free-tier rule, expressed through the request/token caps, not a USD cap.
