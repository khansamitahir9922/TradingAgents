## Goal
Implement the `Instrument` contract from Part H, with its lifecycle and a stable internal ID that never changes and is never reused (ADR-003).

## Allowed files
- `investment_engine/market/__init__.py`, `investment_engine/market/instruments.py` (new)
- `tests/engine/test_instruments.py` (new)
- `docs/tasks/M1-03.md`, `PROGRESS.md`

## Contracts
```python
class AssetClass(StrEnum): EQUITY, ETF          # CRYPTO is reserved (Part L): not accepted in M1
class InstrumentStatus(StrEnum): ACTIVE, DELISTED, SUSPENDED

@dataclass(frozen=True)
class Instrument:
    instrument_id: str      # ^(EQ|ETF)_[A-Z]{2}_[A-Z0-9]+(_[0-9]+)?$, e.g. "EQ_US_NVDA"
    asset_class: AssetClass
    currency: str           # ISO 4217
    exchange: str           # ISO 10383 MIC, e.g. "XNAS"
    timezone: str           # IANA name, validated with zoneinfo, e.g. "America/New_York"
    status: InstrumentStatus
    active_from: date
    active_to: date | None
    def is_active_on(self, d: date) -> bool   # active_from <= d and (active_to is None or d < active_to)

class InstrumentRegistry:   # in memory; the SQLite version is M1-05
    def add(self, instrument: Instrument) -> None   # a duplicate ID raises; there is no remove
    def get(self, instrument_id: str) -> Instrument  # unknown raises KeyError
```

## Implementation choices
**Resolved**
- **ID format** `<ASSET>_<COUNTRY>_<MNEMONIC>[_<n>]`. The mnemonic is usually the ticker **at creation** and is **never changed** when the ticker changes. A later, different instrument that reuses a ticker gets a suffix (e.g. `EQ_US_ABC_2`).
- The ID's asset prefix must match `asset_class`.
- **Lifecycle rules:**
  - `ACTIVE` ⇒ `active_to is None`;
  - `DELISTED` ⇒ `active_to` is set;
  - `active_to > active_from`.

  Validity is half-open: `[active_from, active_to)`.
- **No delete or remove anywhere.** "Never reused" is enforced by having no removal path.

**Unresolved:** none. NVDA's seed values are set in M1-17.

## Acceptance tests
- A valid `EQ_US_NVDA` instrument is built. A bad ID format, or a prefix that doesn't match the asset class, raises.
- An invalid timezone or currency raises.
- The lifecycle rules above are each tested, and `is_active_on` is checked at its boundaries.
- `CRYPTO` is rejected in M1.
- The registry rejects a duplicate ID and has no removal method.

## Out of scope
Persistence (M1-05), symbol lookup (M1-04), corporate actions.
