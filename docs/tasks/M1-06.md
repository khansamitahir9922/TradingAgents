## Goal
Define the `TradingCalendar` port (Law 6) and the US equities implementation for **regular sessions**: 09:30–16:00 `America/New_York`, returned in UTC, correct across daylight-saving changes. Holidays and half-days come in M1-07.

## Contracts
```python
@dataclass(frozen=True)
class Session:
    date: date             # exchange-local date
    open: datetime         # UTC
    close: datetime        # UTC
    is_half_day: bool

class CalendarRangeError(LookupError): ...

class TradingCalendar(Protocol):
    timezone: str
    covered_from: date
    covered_to: date                                   # inclusive
    def is_session(self, d: date) -> bool
    def session(self, d: date) -> Session              # not a session -> ValueError
    def sessions_between(self, start: date, end: date) -> list[Session]   # inclusive
    def next_session(self, d: date) -> Session         # strictly after d
    def previous_session(self, d: date) -> Session     # strictly before d
    # any date outside [covered_from, covered_to] -> CalendarRangeError

class UsEquitiesCalendar(TradingCalendar):
    def __init__(self, *, covered_from, covered_to, holidays=frozenset(), half_days=None): ...
```

## Implementation choices
**Resolved**
- **Exchange-local wall times, converted to UTC with `zoneinfo`.** DST is handled by the time-zone database, not by hand.
- **Coverage is explicit**, and a date outside it raises rather than guessing. M1-07 supplies the real data and its range.
- **Weekends are never sessions.**

**Unresolved:** none.

## Acceptance tests
- `2024-03-08` opens at 14:30 UTC (EST). `2024-03-11` opens at 13:30 UTC (EDT, after the 10 March change). `2024-11-04` opens at 14:30 UTC (after the 3 November change). Closes are checked the same way.
- Saturdays and Sundays aren't sessions.
- `sessions_between`, `next_session` and `previous_session` across a weekend.
- Out-of-range dates raise `CalendarRangeError`.
- The tests pass regardless of the machine's time zone.

## Out of scope
Holiday data, half-days and special closures (M1-07); other markets.
