## Goal
Measure directional views against the actual base rate, with sample sizes, abstentions and unavailable outcomes visible. Add information coefficient as a descriptive research metric, without claiming strength is a forecast or probability.

## Allowed files
- `investment_engine/evaluation/metrics.py` (new)

- `docs/tasks/M2-09.md`, `PROGRESS.md`

## Contracts
```python
@dataclass(frozen=True)
class MetricValue:
    key: str; value: float | None; n: int; unavailable_reason: str

@dataclass(frozen=True)
class DirectionEvaluation:
    config_version: str; basis: ReturnBasis; horizon_sessions: int
    eligible_views: int; directional_views: int; neutral_views: int
    abstain_views: int; unavailable_outcomes: int
    metrics: tuple[MetricValue, ...]
    outcome_refs: tuple[ReturnObservation, ...]

def evaluate_direction(views, outcomes, *, config: LabelConfig) -> DirectionEvaluation
```

## Rules
1. Join by instrument, provider, prediction session and declared outcome horizon/basis; duplicates or mismatched targets raise. Signed directional score is +strength for BULLISH and -strength for BEARISH. NEUTRAL and ABSTAIN aren't predictions of a flat market.
2. Directional accuracy uses BULLISH/BEARISH views with available, non-zero outcomes. Report zero-outcome exclusions, coverage, neutral and ABSTAIN counts separately. Always-up and last-period-direction baselines use **exactly the same scored dates**. Last-period direction must have completed and become available before prediction T; unavailable baseline predictions reduce and identify its paired comparison sample.
3. Report observed positive base rate, always-up accuracy, model accuracy and paired accuracy difference. Also report always-up on the full eligible outcome set so selective abstention cannot silently improve the comparison. No claim of improvement from unmatched samples.
4. Information coefficient is Spearman rank correlation of signed score and realised target return for BULLISH/BEARISH views with available outcomes (including zero returns, unlike directional accuracy); report this sample separately. Ties receive average ranks. Constant/insufficient samples return `None` with a reason, not NaN or zero. Strength remains a heuristic, not calibrated probability. Overlapping multi-session outcomes are disclosed; no significance claim is derived from naive independent-sample assumptions.
5. A numeric zero-return baseline is reserved for numeric forecasts in M9; don't invent numeric predictions from rule strengths. Buy-and-hold is an investment-performance benchmark in M2-10, not a directional-accuracy comparator.
6. Define last-period direction as the sign of the same-basis h-session return ending at the prediction session's close (starting h sessions earlier), read at prediction T. Its whole outcome must already be available. Do not use yesterday's still-unfinished forward h-session label or silently substitute a one-day horizon.

## Implementation choices
Resolved: no new scipy dependency is necessary; small hand-ranked reference examples define the algorithm. Report sample counts with every metric. No unapproved tuning or instrument selection.

Unresolved: OPEN-09 metric/promotion choices remain provisional; metrics do not authorize promotion.

## Acceptance tests
- Hand-built up/down/zero outcome table verifies accuracy, positive base rate, always-up, neutral/abstain handling and paired counts.
- Last-period outcome available after prediction T is excluded from that baseline; no future data read.
- Perfect positive/negative rank examples, ties and constant arrays test IC; unavailable metric stays `None` with a reason.
- Selective abstention exposes its reduced dates and full-population baseline; mismatched horizon/provider and duplicate views rejected.

## Out of scope
Probability calibration, numeric forecast metrics, automatic promotion and financial advice.
