## Contracts

The [M5 shared contracts](M5-README.md#shared-contracts) and accepted ADR-010 govern this task. Proposed rules for this task:

1. Implement LedgerFingerprints with the same economic-fingerprint inputs/excluding_order semantics as M4; add the typed LedgerBalances projection branch to build_snapshot.
2. Ledger cash/holdings plus OMS as-of reservations drive available cash/shares and pending exposure. UNKNOWN reserves in full, pending SELL never frees cap room; fees match actual supported fee policy.
3. Use the already reserved LEDGER source for new activated-account snapshots. Legacy optional fields must not be added to old canonical payloads or alter old IDs. Missing cost is not zero.
4. Preserve last_clear drawdown epochs, source coverage, action-compatible marks and Missing gate inputs. This task exposes/directly tests the adapter; production wiring waits for M5-10, so no forward imports.
5. Capture a genuine M4-format snapshot fixture from accepted code, with generation command/hash. Do not hand-invent a fixture claimed to come from old code.
