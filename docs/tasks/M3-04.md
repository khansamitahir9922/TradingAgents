## Goal
Record who did what, append-only, in the same transaction as the change it describes (architecture Part F "Audit", Part H `AuditEvent`, B2).

## Contracts
```python
class ActorKind(StrEnum): OPERATOR = "OPERATOR"; PROCESS = "PROCESS"

@dataclass(frozen=True)
class Actor:
    kind: ActorKind
    actor_id: str            # operator id, or a process name such as "core-engine" or "admin-cli"
    role: str | None         # ADMIN | TRADER | VIEWER for operators; None for processes
    os_user: str | None      # the local login that ran the command, for attribution only

@dataclass(frozen=True)
class AuditEvent:
    actor: Actor
    action: str              # dotted verb, e.g. "intent.approve", "limits.publish", "account.set_autonomy"
    target_type: str; target_id: str
    before: object | None; after: object | None    # canonical-codec values (M2-07), never raw dicts of secrets
    at: datetime             # UTC, from the injected Clock
    reason: str
    correlation_id: str      # groups the events of one command or pipeline run
    idempotency_key: str     # the same key and content is one event
    event_id: str = field(init=False)   # "aud-" + SHA-256 of the canonical content

class AuditStore:
    def __init__(self, db: Database) -> None
    def append(self, event: AuditEvent) -> None        # must be inside the caller's open transaction
    def for_target(self, target_type: str, target_id: str) -> list[AuditEvent]
    def between(self, start: datetime, end: datetime) -> list[AuditEvent]
```

## Rules
1. **Same transaction.** `append` raises unless `db.in_transaction` is True: the port's managed scope (M3-02 rule 1), not merely a driver-level transaction. An audited change and its event therefore commit or roll back together. A change that must be audited and is not is a defect, tested in each later task.
2. **Append-only.** UPDATE, DELETE and TRUNCATE are refused by triggers; an identical append (same `event_id`) is a no-op; the same id with different content raises.
3. **No secrets; only codec-supported shapes.** `before` and `after` hold registered domain values only (the M2-07 codec refuses unknown types). The codec is **not** extended in M3 (Codex B2): M3 contracts use tuples, never sets. A field that is a set by meaning is stored as a sorted, de-duplicated tuple, normalized in `__post_init__`. Existing lineage and evaluation bytes and ids are therefore unchanged by construction. **Fresh-process decoding:** `investment_engine/audit/registry.py` holds the fixed list of modules whose registered types events may contain. `AuditStore.__init__` imports them, so a new process can decode every stored event without the writer's imports. This task creates the list empty; each later task that adds an auditable type adds its module there (it's in their allowed files). Free-text `reason` is stored as given and is length-limited (1,000 characters). Nothing reads environment variables. A test proves a DSN-shaped string in configuration never reaches an event unless a caller passes it explicitly.
4. **Attribution, not authentication.** `os_user` comes from the operating system for the record only; roles are checked against the operator registry (M3-05). Logins arrive in M8.
5. Times come from the injected Clock; `at` must be UTC; events sort by (`at`, `event_id`).

## Acceptance tests
- An audited change rolled back leaves no event; committed, both exist.
- Append outside a transaction raises; identical append is a no-op; conflicting content raises.
- UPDATE, DELETE, TRUNCATE and conflicting inserts are refused.
- Round trip of every field; queries by target and time range in order.
- An unregistered type or a non-UTC time is refused.
- In a fresh subprocess that imports only the audit module, an event holding a test-registered type listed in the registry decodes exactly. Each later task repeats this for its own types: PolicyRules with an empty and a non-empty restricted list, RiskLimits, Halt, AutonomySetting, the decisions and the intents.
- The genuine `57d4316` evaluation record and a current lineage record keep their ids after all M3 types are registered.
