## Goal
Load US equities holidays, early closes and special closures from a **cited data file** covering the years M1 imports, so sessions are correct and any date outside the data fails loudly.

## Allowed files
- `investment_engine/market/calendar/data/us_equities.json` (new)
- `investment_engine/market/calendar/us_equities.py` (add a loader)
- `pyproject.toml`: **only** `[tool.setuptools.package-data]`, adding `market/calendar/data/*.json` to the `investment_engine` entry
- `tests/engine/test_calendar_holidays.py` (new)
- `docs/tasks/M1-07.md`, `PROGRESS.md`

## Contracts
**`us_equities.json`:**
```json
{
  "market": "US equities (NYSE/Nasdaq regular sessions)",
  "timezone": "America/New_York",
  "covered_from": "2019-01-01",
  "covered_to": "2026-12-31",
  "regular": {"open": "09:30", "close": "16:00"},
  "closures": [{"date": "YYYY-MM-DD", "reason": "...", "source": "..."}],
  "early_closes": [{"date": "YYYY-MM-DD", "close": "13:00", "reason": "...", "source": "..."}],
  "sources": [{"id": "...", "title": "...", "url": "...", "retrieved": "YYYY-MM-DD"}]
}
```
`load_us_equities_calendar() -> UsEquitiesCalendar` reads the packaged file with `importlib.resources`.

## Implementation choices
**Resolved**
- **A maintained, cited data file in the repository, not a calendar library.** It adds no dependency, every date is reviewable in one diff, and the data cites its sources. The cost is a yearly update, which is accepted.
- **Coverage is 2019-01-01 to 2026-12-31**, matching the default daily import range (M1-13) and the current year. Outside it, `CalendarRangeError` is raised.
- **Special closures** (unscheduled market closures) are included with their reason, e.g. 9 January 2025 (national day of mourning for President Carter). This is to be confirmed against the cited source.
- **Every entry cites a source.** The values are taken from the exchanges' published holiday and early-close schedules, including archived pages for past years. **They're not written from memory.**

**Unresolved:** none. A reviewer checks the data against the cited sources.

## Acceptance tests
- Each closure in the file isn't a session, and each early close ends at its stated time in UTC.
- Spot checks, each **verified against the cited source while writing the data** (the test names the source ID):
  - a Good Friday;
  - Juneteenth (observed from 2022);
  - Thanksgiving and the early close the day after;
  - Christmas Eve's early close when it's a weekday;
  - an Independence Day observed on a Friday or Monday;
  - the 2025-01-09 special closure.
- Weekday sessions per year are counted and checked against the expected count (e.g. 252 for 2024, if confirmed by the source).
- A validation test: every date in the file is within coverage and isn't a weekend; there are no duplicates; every entry has a source.
- The packaged data loads from an installed (non-editable) copy, which the smoke check covers.

## Out of scope
Exchanges outside the US, crypto calendars, and pre- or post-market sessions.
