## Goal
Compute the indicators that option A's two strategies need: SMA(50), SMA(200), RSI(14), and the distance of the close from SMA(200). They're computed on the split-adjusted daily view as of T. Each is a registered, versioned feature.

## Allowed files
- `investment_engine/quant/indicators.py` (new)
- `tests/engine/test_indicators.py` (new)
- `docs/tasks/M2-02.md`, `PROGRESS.md`

## Contracts
```python
def sma(closes: Sequence[float], window: int) -> float | None          # None before `window` values
def rsi(closes: Sequence[float], window: int = 14) -> float | None     # Wilder's smoothing; None before window + 1 values
def distance_from(close: float, average: float) -> float                # (close - average) / average

DEFINITIONS: tuple[FeatureDefinition, ...]   # sma50, sma200, rsi14, dist_sma200, all on SPLIT_ADJUSTED_AS_OF
```

## Rules
1. **Inputs end at T.** An indicator at T uses only bars with session close ≤ T, from M2-00 at the same `at`.
2. **Warm-up:**
   - SMA(n) needs n closes;
   - RSI(14) needs 15 closes, plus a seeding window stated in the code;
   - before that the value is `None`, **never** a partial-window value.
3. **RSI** uses Wilder's smoothing, seeded by the simple average of the first 14 gains and losses. With gains > 0 and losses = 0 it is 100; with losses > 0 and gains = 0 it is 0; when both are zero it is 50. Each subsequent average is `(previous_average * (window - 1) + current_change) / window`.
4. **No look-ahead:** appending a future bar never changes a value at an earlier T.

## Implementation choices
**Resolved:** formulas above define the draft contract. Implementation documents its seed and recurrence. Non-finite values, Decimal inputs, non-positive prices/averages and invalid windows raise. Missing sessions cannot be compressed into a falsely continuous indicator window: M2-03 supplies calendar-validated consecutive sessions.
**Unresolved:** none.

## Acceptance tests
- Hand-computed small series for SMA and RSI, including gains-only, losses-only, flat and a post-seed recurrence; invalid-input cases.
- Warm-up: `None` until exactly the required count.
- **No look-ahead:** values at T are identical whether or not later bars exist.
- **Across a synthetic 10-for-1 split:** adjusted closes and returns have no artificial 90% discontinuity; raw closes do. SMA(200) equals a manually adjusted reference. Do not assert that one split moves a 200-day average by 90%.
- Each definition is registered with its warm-up.

## Final interfaces (implemented; extensions accepted in principle by Codex's review of `57d4316`, 2026-10-15)
