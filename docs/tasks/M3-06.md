## Goal
Store risk limits and policy rules as versioned, append-only configuration per account, plus drawdown halts, so every decision names the exact version it used (Part F: "Policy rules (versioned)", "Risk limits (versioned)").

## Contracts
```python
@dataclass(frozen=True)
class RiskLimits:
    version: str                          # "risk-<n>" per account, assigned on publish
    max_position_fraction: Decimal        # D1: 0.10 of account value
    max_gross_exposure_fraction: Decimal  # D2: 1.00 (no borrowing)
    long_only: bool                       # D2: True; v1 refuses False
    drawdown_halt_fraction: Decimal       # D3: 0.15
    max_order_adv_fraction: Decimal       # D4: 0.01
    adv_sessions: int                     # D4: 20
    max_new_buys_per_session: int         # D5: 5
    min_price: Decimal                    # D6: 5 (USD)
    min_quantity: Decimal                 # D9: 1 share; whole shares only

@dataclass(frozen=True)
class PolicyRules:
    version: str                          # "policy-<n>" per account
    restricted: frozenset[str]            # D8: instrument ids
    session: str                          # D7: "REGULAR_ONLY"
    order_type: str                       # D7/D13: "LIMIT"
    time_in_force: str                    # D7: "DAY"
    limit_band_fraction: Decimal          # D13: 0.01
    view_timeframes: frozenset[str]       # D12: {"D1"}

@dataclass(frozen=True)
class Halt:
    account_id: str; halted: bool; at: datetime; by: str; reason: str; limits_version: str

class LimitStore:
    def publish_risk(self, account_id, limits_without_version, *, by: Actor, reason) -> RiskLimits
    def publish_policy(self, account_id, rules_without_version, *, by: Actor, reason) -> PolicyRules
    def risk_at(self, account_id, at) -> RiskLimits          # raises NoLimits if none effective
    def policy_at(self, account_id, at) -> PolicyRules       # raises NoLimits if none effective
    def set_halt(self, account_id, *, at, limits_version, reason) -> Halt   # by the risk check (M3-11)
    def clear_halt(self, account_id, *, by: Actor, reason) -> Halt          # Admin only
    def halt_at(self, account_id, at) -> Halt | None
```

## Rules
1. **Fail closed.** No effective limits means `NoLimits`, which the checks turn into rejections (M3-10, M3-11). The shipped `proposed_limits.json` is applied only when an Admin runs `limits publish --file` explicitly; its header says the values are owner decisions D1–D9 and D13.
2. **Versions never change.** Publishing creates the next version, effective from its publish time; old versions stay readable. A restricted-list change (`restricted add|remove ID --reason`) publishes a new PolicyRules version. Each publish is audited in the same transaction.
3. **Validation.** Fractions are Decimal in (0, 1] (gross exposure up to exactly 1); integers are positive; `long_only=False` is refused in v1; unknown keys in a file are refused; floats in the JSON are refused (strings or integers only), so no binary rounding enters money rules.
4. **Halts are latched.** A halt stays until an Admin clears it (D3), even if the account recovers. Halt history is append-only and audited.
5. Admin role required for publish, restricted changes and clearing a halt (M3-05 rule 2).

## Acceptance tests
- No limits: lookups raise `NoLimits`. Publishing the proposed file gives version 1 with exactly the D-values.
- Versions answer "what was effective at T" across several publishes; old versions unchanged; UPDATE and DELETE refused.
- Each validation refusal (float, out-of-range fraction, unknown key, `long_only=false`) publishes nothing and writes no event.
- Restricted add and remove create new policy versions with audit events.
- A halt persists after recovery until cleared by an Admin; a Trader can't clear it.

## Out of scope
Sector or industry concentration (no sector data yet; a future limit), per-strategy limits, intraday limits.
