## Goal

Build the instrument that will measure OPEN-10: count every LLM request, input/output tokens and tool call of one TradingAgents run, offline, with a fake LLM.

## Dependencies

none. Same-package predecessors must be committed and checked; external prerequisites merged (M5 is merged locally).

## Allowed files

- `investment_engine/research/__init__.py`
- `investment_engine/research/usage.py`
- `tests/engine/test_usage_counter.py`
- `tests/engine/research_fakes.py` (fake chat model and fake data tools)
- `docs/tasks/M6-00.md`, `docs/tasks/M6-README.md` (task status/check record only), `PROGRESS.md`

Anything else triggers the stop rule.

## Contracts

The [M6 shared contracts](M6-README.md#shared-contracts) govern this task.

1. A LangChain `BaseCallbackHandler` records per call: run ID, agent node, model name, start/end (injected clock), prompt message count, token usage from `usage_metadata`/`llm_output` when the provider reports it, and **unknown** (not zero) when it does not.
2. Tool calls are counted with name, arguments hash and result size.
3. A fake chat model drives the real upstream graph (`TradingAgentsGraph`) with stubbed data tools, no network: proves the counter sees every agent (4 analysts, bull/bear, research manager, trader, 3 risk debaters, PM) for the configured rounds.
4. Output: a `UsageSummary` (requests, tokens in/out or unknown, tool calls, per agent) used by M6-06 and M6-11.

## Acceptance tests

- Fake run with 1 debate round and 1 risk round: exact expected request count per agent, totals match.
- A provider reporting no token usage yields unknown tokens and a warning, never 0.
- No socket is opened (the conftest network guard stays active); no API key is read.
