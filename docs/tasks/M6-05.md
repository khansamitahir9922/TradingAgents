## Goal

Turn a run's typed output into a ResearchContext, honestly labelled.

## Dependencies

M6-04. Same-package predecessors must be committed and checked; external prerequisites merged (M5 is merged locally).

Anything else triggers the stop rule.

## Contracts

The [M6 shared contracts](M6-README.md#shared-contracts) govern this task.

1. Rating from `final_decision_structured.rating` (source=typed); if absent, upstream's text rating parser result with source=free-text-fallback and a warning; if neither, no context (outcome FAILED: no rating).
2. Trader action and levels from `trader_proposal_structured`; levels converted to Decimal exactly from their string form, else None with a warning; never inferred from text.
3. `valid_until` per D51 from the injected calendar; horizon recorded.
4. Warnings: fallback used, missing levels, analyst report empty, tool errors seen, usage unknown.

## Acceptance tests

- Typed, fallback and missing-rating cases; percentage/ranged levels end as None with warning.
- valid_until is the 5th session close across a holiday and a weekend.
- A prompt-injected 'execute order' string in a report is stored verbatim and produces no extra field.
