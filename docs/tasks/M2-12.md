## Rules
1. All values come from supplied MarketViews, LineageRecords and EvaluationRuns. Headline values identify source/run ID, calculation basis, dates/cutoff and units. An unavailable number shows its reason, never zero. Generated time is explicit/injected, not a system-clock read.
2. Chart labels distinguish raw prices from split-adjusted prices and total-return index; strengths are scales, never percentages suggesting probability. Show DataHealth at each historical view, including ABSTAIN reason, warm-up, required sources and BACKFILL_ASSUMED assumptions. For historical views, expiry is assessed at the selected historical T, not today's wall clock.
3. Every research run is labelled `SIMULATED / REPLAY · historical research`. State that initial evaluation is not execution replay; no orders, actual fills, portfolio cash or ledger P&L exist in this report. Real paper mode, autonomy and kill-switch state cannot be inferred: show `PAPER EXECUTION NOT CONNECTED`, `AUTONOMY NOT CONFIGURED` and `TRADING STATUS CANNOT BE VERIFIED`, with no claim that submissions are blocked.
4. Show cost scenarios, matched benchmarks, sample sizes, neutral/abstain/unavailable counts, fold boundaries and limitations. OPEN-09 assumptions and promotion thresholds remain visibly provisional with promotion not assessed. No claim of profitability, significance or model probability is manufactured.
5. Static dark panels, readable headline numbers and status chips with text/icons; no colour-only status. Escape all supplied strings, including provider metadata and reasons. A malicious symbol/reason cannot execute JavaScript. Use local inline SVG for the simple price/view chart; no external CDN/network requirement or dashboard API.
6. Rendering is deterministic for the same records and supplied generated time. No write to market-data store, Operational DB, upstream TradingAgents or the CLI. Caller decides where to save the returned HTML; no new command is added here.

## Implementation choices
Resolved: standard-library templating/escaping and generated inline SVG keep this scoped to one report task; no new frontend dependencies or live dashboard components. Design rules are applied without pretending the later M8 runtime exists.

Unresolved: independent review of the report's unavailable-state labels and provisional evaluation disclosures before implementation acceptance.

## Acceptance tests
- A synthetic fixture renders exact source-backed values, view directions/strengths, lineage links and matched costs/benchmarks.
- ABSTAIN, missing metric, missing source, warm-up, backfill and unresolved trading status have honest text; unavailable values never become 0.
- Raw/adjusted/total-return labels cannot be interchanged. No actual ledger/broker figure is claimed.
- Untrusted HTML/script text is escaped; no remote resource or network access required. Statuses remain identifiable without colour.
- Byte-identical output for identical inputs/time; store hashes unchanged; all displayed headline values trace to provided run/lineage IDs.

## Out of scope
Dashboard/API/authentication/roles (M8), real paper execution, new CLI commands and M2 model training.
