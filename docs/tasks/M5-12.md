## Contracts

The [M5 shared contracts](M5-README.md#shared-contracts) and accepted ADR-010 govern this task. Proposed rules for this task:

1. Implement C7 and proposed D42: custom-format pg_dump; tool path/version checks; private libpq environment/service credentials; sanitized failures; no secret-bearing DSN argv.
2. After successful DB dump, inventory/copy immutable closed market files with hashes and safe relative paths, and verify every restored DB market reference has a copied source. Record actual capture interval, not a fictitious atomic cross-store timestamp.
3. Publish a successful manifest only after dump and copies verify. Failed/cancelled jobs leave explicit incomplete evidence, never overwrite a prior successful backup or delete history.
4. Restore verification is local/disposable-only using the existing safe PostgreSQL test guard. Refuse owner/live/nonlocal database names/targets and traversal/symlink escapes. Reuse password-redacting test runner.
5. Document a daily Windows schedule and enabling procedure; do not install it or run a real owner-data backup/restore without separate authorization. A same-disk copy is not claimed to protect against disk loss.

## Implementation choices

- **Owner-approved, 2026-10-21:** D35-D44 and ADR-010 v0.2; do not silently choose a different policy.
- No new process, broker, account authority, serializer rewrite or order edge. Fail explicitly when a required source/contract is unavailable.
- All production time uses injected clocks; money/quantities are Decimal; source/provider separation and no-look-ahead rules apply.
- A discovered architecture gap, out-of-scope file or new test failure stops the package and is reported before dependent work.

## Acceptance tests

- Disposable live PostgreSQL journal/audit/source data dump/restore preserves counts, hashes, per-unit balance and report totals.
- A new append-only market partition during dump is either safely included as a superset or the reference check fails; no false complete manifest.
- Partial copies, corrupt files/dump, unavailable tools, failed pg_dump and unsafe paths remain FAILED/incomplete.
- Credentials absent from argv/logs/manifests/errors, including failed command/setup output.
- Restore cannot touch an owner database, restores no secrets/kill flag, and leaves execution disabled.
