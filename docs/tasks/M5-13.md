## Contracts

The [M5 shared contracts](M5-README.md#shared-contracts) and accepted ADR-010 govern this task. Proposed rules for this task:

1. Use plain pytest, deterministic fixed seeds and documented run counts. Extend the existing process harness without reducing its tests or weakening timeouts.
2. Generate independent hand-calculated expected currency/quantity conservation, source deduplication and cost preservation; do not calculate expected output by calling the same posting code.
3. Probe all journal SQL mutation/replacement/sealed-header routes, source conflicts, late-fill/action correction closure, per-account race isolation, snapshot differences and incident permissions.
4. Kill only disposable child processes/connections. Never stop the owner PostgreSQL server. Verify rollback/restart and outbox consumer replay.
5. Boundary probes forbid Core broker imports/private sim schema, worker ledger writes and any extra secret reader. Existing accepted R5 and cancellation checks remain unchanged.

## Acceptance tests

- At least 200 fixed-seed accounting flows; every represented unit balanced, holdings equal lot quantities, cost conservation exact.
- At least 50 repetitions for competing posting, fill/proposal and incident CAS races, with no duplicate effect or lost update.
- Two real process crash points before/after ledger commit, duplicate fill delivery and interrupted snapshot capture all recover correctly.
- Seeded independent cash/share/open-order/missing-fill discrepancies are detected, never repaired automatically.
- All retained M4 invariants and legacy-record compatibility cases pass; no missing-DSN skip counted as success.
